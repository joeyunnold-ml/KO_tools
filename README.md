# KO_tools

Workshop facilitation tools for client kickoffs.

## Tools

| Folder | Status | Description |
|---|---|---|
| [`happy-if/`](./happy-if) | ✅ Ready | "We'll be happy if…" — surfaces individual goals before group dynamics homogenize them. Used in Session 1B of the Avis kickoff (May 19 2026). |
| [`exp-canvas/`](./exp-canvas) | ✅ Ready | "Experiment Lifecycle Canvas" — blind-elicits how each person sees the lifecycle, AI-synthesizes a proposal, then opens a collaborative sticky grid (Activities / People / Tools / Pain Points / Hopes × lifecycle stages). Used in Session 2C of the Avis kickoff. |
| [`three-lanes/`](./three-lanes) | ✅ Ready | "Three-Lane Framework" — sort work into Fix It / Test It / Build It. Blind sort + AI conflict analysis surfaces consensus and ranks contested items by disagreement, with discussion prompts and team-level pattern observations. Used in Session 3B of the Avis kickoff. |
| [`priorities/`](./priorities) | ✅ Ready | "Priority Vote" — closing exercise. Vote on priorities, then assign ML Owner / Avis Counterpart / Access Needed / First Action live on the projected screen. Output is a shareable read-only commitment table at `/votes/[code]`. Used in Session 4 of the Avis kickoff. |

See each tool's own `README.md` for setup instructions.
